# 벤치마크 요약 — sweep

`run-multi.sh` 가 생성한다. 손으로 고치지 않는다 — 재실행하면 덮인다.

- 스토리지 **tmpfs** · 재고 = VU×2 (전원 차감) · 회차 **6회**
- 값은 **중앙값 (최소~최대)**. 회차별 원값은 [`results/sweep/raw.tsv`](./sweep/raw.tsv) 한 줄씩
- 회차별 k6 출력 원문은 저장소에 두지 않는다. 수치가 전부 raw.tsv 에 있고, 원문은 재실행하면 다시 나온다
- 주문 p95 는 `order_duration` — 주문 요청만 잰다. 처리율은 `order_success` 의 초당 건수
